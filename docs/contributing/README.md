# Contributing

Read the repository [contribution guidelines](https://github.com/ohbus/twitter-backend-java/blob/master/CONTRIBUTING.md)
and [code of conduct](https://github.com/ohbus/twitter-backend-java/blob/master/CODE_OF_CONDUCT.md)
before opening a pull request.

The short version:

1. Choose or discuss an issue.
2. Branch from current `master`.
3. Make one focused change with tests.
4. Run `./mvnw clean verify`.
5. Rebase on `master` and open a focused pull request.

See the [development workflow](workflow.md) and
[issue/review guide](issues-and-reviews.md) for project-specific details.
