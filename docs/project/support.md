# Support and community

- Use [GitHub Issues](https://github.com/ohbus/twitter-backend-java/issues) for reproducible defects and accepted work.
- Use [GitHub Discussions](https://github.com/ohbus/twitter-backend-java/discussions) when enabled for questions and design discussion.
- Follow the [code of conduct](https://github.com/ohbus/twitter-backend-java/blob/master/CODE_OF_CONDUCT.md) in every project space.
- Report security concerns privately using the repository
  [security policy](https://github.com/ohbus/twitter-backend-java/blob/master/SECURITY.md), not a public issue.

Include the application version, Java version, active profile, reproduction
steps, and sanitized logs when asking for technical help.
