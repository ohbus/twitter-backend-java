# Getting started

Choose the smallest setup that matches your task:

| Goal | Setup |
| --- | --- |
| Try the complete stack | Configure `.env`, build the JAR, then run `docker compose up -d` |
| Develop the backend | Start dependencies with `docker-compose.dev.yml`, then run Maven |
| Run automated checks | `./mvnw clean verify` |

Continue with [installation](installation.md), then review
[configuration](configuration.md) and the [development workflow](development.md).
